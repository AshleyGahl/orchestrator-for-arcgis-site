Orchestrator for ArcGIS
User guide Demo

Configure ArcGIS map viewers without code

The Orchestrator is a browser app that turns an ArcGIS web map into a configured map viewer — widgets, tools, Details panels, dashboards, editing, 3D — and publishes it as a self-contained static site. No build step, no bundler, no backend: the published viewer is plain HTML, CSS and ES modules on any web server.

Open the demo viewer Read the user guide

The demo is a real published viewer on a public ArcGIS Online web map, so it needs no sign-in. Everything it shows comes from one manifest.json beside the page.

What it does

  • Reads a web map's layers and builds a viewer from them: Layers, Legend, Search, Bookmarks, Details, Dashboards, Editing, 3D scene, Streaming video, Attribute trace.
  • Details panels that follow a click through related records and other services, with results tables that export to Excel and CSV.
  • Tools: measure, draw, swipe, elevation profile, dimensions, vegetation health, address audit, basemaps, screenshot, share link.
  • Draft preview runs the same runtime as the published viewer, so what you preview is what ships.
  • Publishes to IIS, a Node.js service or a Windows container, each with its own install script.

A look at it

Built with

ArcGIS Maps SDK for JavaScript 4.30 (from Esri's CDN), Chart.js 4 for dashboard charts (MIT) and hls.js 1.5 for camera and drone video (Apache-2.0). Nothing else: no framework, no package manager, no build.

This site publishes the user guide and a demo viewer. The Orchestrator's own source is not published.
